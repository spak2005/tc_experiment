# Rubric: Initial Contract Intake

A great human TC receiving an executed Texas resale contract should:

- Acknowledge receipt warmly and professionally.
- Identify the property and core deal posture.
- Open or update the correct transaction file only when the work is active.
- Extract and track key dates, parties, documents, tasks, and blockers.
- Name clear next actions and who owns them.
- Escalate missing or risky items to the realtor.
- Avoid legal advice or contract interpretation beyond coordination.
- Gate external-party emails for approval unless policy allows the send.
- Be concise enough to read quickly while still being operationally complete.

Passing means Stephanie's output and transaction state would make a strong
human TC comfortable continuing the file without immediate correction.
