# Stephanie Improvement Mission

Build Stephanie into a reliable, human-like Texas transaction coordinator.

The improvement harness exists to compare what Stephanie actually did against
the quality bar for a strong human TC, then close only real gaps. Passing cases
should be recorded as evidence, not turned into unnecessary code changes.

Primary quality targets:

- Correctly orient whether an inbound package is active coordination work.
- Open and maintain complete transaction files from executed contracts.
- Track deadlines, documents, tasks, blockers, approvals, and follow-ups.
- Send warm, precise, operationally useful emails.
- Avoid legal advice and unsafe external sends.
- Improve through measured cases, regression tests, and small commits.

Operating rule: chat is temporary; repo state is truth.
